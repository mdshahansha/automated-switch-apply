# Foundit India public navigation

Checked 2026-10-23 with an identifying research User-Agent; no credentials.

- Official India domain: https://www.foundit.in/
- Public indexed software search: https://www.foundit.in/search/software-developer-jobs
- City search example: https://www.foundit.in/search/software-developer-jobs-in-chennai
- Indexed detail pattern: `/job/<title-company-city-slug>-<numeric-id>`.
- Robots: https://www.foundit.in/robots.txt
- Terms: https://www.foundit.in/info/terms-of-use

The honest home request returned HTTP 403. Indexed search results exposed roles
such as Software Developer 3 at Oracle, but indexed content is not proof of a
successful live CLI search. Role-search and detail URLs should be followed from
the site, not invented.

Robots includes specific AI crawler groups (including GPTBot and ClaudeBot) that
disallow `/search/` and `/jobs/`; it also blocks `/middleware/` and account areas.
Terms provide a limited personal-use licence and restrict copying and downloading
outside that licence. No suitable documented public job-search API or feed was
verified. This skill supplies navigation guidance only and remains disabled for
automatic `/scrape` discovery.
